# Student Performance Prediction 📊

## Project Overview
This project focuses on analyzing student academic performance and predicting performance categories using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Workflow
1. Data Loading and Exploration
2. Data Preprocessing
3. Handling Missing Values
4. Data Encoding
5. Exploratory Data Analysis
6. Decision Tree Classification
7. Model Evaluation and Visualization

## Machine Learning Algorithm
Decision Tree Classifier

## Project Objective
To analyze student academic data, identify performance patterns, and predict student performance categories.
